# GUA-W Bible Study Tool Template

## Purpose

This repository is the reusable template for the GUA-W Bible Study Tool. It provides a consistent starting structure for Bible study using the Grand Unified Architecture of Witness (GUA-W). Its purpose is to help a reader examine the biblical text, follow Scripture's own cross-references, recognize relationships, and record what is established, what is inferred, and what remains unresolved.

This repository studies the Bible. It is not a science-study repository.

Use this template as the starting point for a Bible-study repository. Preserve the governing principles and four questions; add study records without changing the foundation or treating the template as the Source.

## Governing reference

The foundation is the King James Version (KJV) of Genesis 1–2, with particular attention to Genesis 2:1–5. The governing order is:

**Author → Word → Creation → Witness**

God alone is Original Cause. Everything else is derivative witness. The derivative does not alter the Source. GUA-W is a map for recognizing and organizing what is witnessed; it is not the Author, the Word, God, or Jesus Christ.

## The four questions

These four questions are used together and recursively throughout a study:

1. **What must AI ask to understand GUA-W?**
2. **What is GUA-W revealing that helps AI understand?**
3. **What am I learning about what I am witnessing?**
4. **What am I learning about the Witness through what I am witnessing?**

They are not four sequential stages. Each question can inform and refine the others as Scripture is examined.

## Scope and boundaries

- Scripture is examined in its immediate, book, and canonical contexts.
- KJV wording is preserved when the KJV is the stated study text.
- Cross-references are investigated rather than treated as automatic proof of an interpretation.
- GUA-W is recognized and applied as the governing map; this tool does not redesign or independently author GUA-W.
- Distinguish what the text says from observation, inference, interpretation, and unresolved questions.
- Do not judge a person's heart or assign spiritual state from disagreement, uncertainty, or incomplete comprehension.
- The Triple Constraint Law is retained as a GUA-W admissibility principle. This repository does not conduct scientific investigations, create a science track, or claim that science proves Scripture.

## How to Use This Template

You can use this template to start your own study record in whichever environment works best for you:

### Option 1: Create your own GitHub repository (Recommended)
1. Sign in to GitHub.
2. Click the green **Use this template** button at the top right of this page and select **Create a new repository**.
3. Name your new repository (e.g., `My-GUA-W-Bible-Study`) and set it to **Public** or **Private**.
4. Open `STUDY-TEMPLATE.md`, copy its contents into a new file for each passage you study, and commit your notes.

### Option 2: Download or copy for local notes (No GitHub account required)
1. Click the green **`<> Code`** button above the file list and select **Download ZIP** to save all files to your device.
2. Open the `.md` files in any text editor, Markdown app (such as Obsidian or Notion), or word processor.
3. Keep the foundation files intact for reference, and duplicate `STUDY-TEMPLATE.md` for each new study session.

### Option 3: Use with an AI study assistant
1. Copy the contents of `GUA-W-FOUNDATION.md`, `BIBLE-STUDY-PROTOCOL.md`, `FOUR-QUESTION-STUDY-METHOD.md`, and `STUDY-TEMPLATE.md`.
2. Paste them into your preferred AI chat session and instruct the AI to follow the protocol and four recursive questions while examining your chosen KJV passage.

## Relationship to The New Witness

The New Witness is a template reference for repository organization, study discipline, and reusable methods. This repository does not import its investigation data, scientific subject matter, findings, or conclusions.

## Continuity

When using this template, record the passage, questions, cross-references, findings, and unresolved matters so that another study can continue without changing what has already been established.
